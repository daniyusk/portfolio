# Daniyusk Portfolio

Personal portfolio built with React, TypeScript, Vite and Tailwind CSS.

The project presents Daniyusk's work, style and developer identity through a responsive interface, custom SVG assets, a terminal-inspired hero section and polished interactive components.

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Lucide React
- class-variance-authority
- clsx
- tailwind-merge

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Run lint:

```bash
npm run lint
```

## Project Structure

```txt
src/
  assets/       Static assets and SVGs
  components/   Reusable UI components
  data/         Portfolio data
  pages/        Page-level views
  routes/       App routes
  styles/       Shared style helpers
```
